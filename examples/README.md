# Examples

`tips/` is a ready-made starter set for your tips folder (by default
`%OneDrive%\Vindictive` or `Documents\Vindictive`; see
[`docs/SETUP.md`](../docs/SETUP.md)).

1. Open the tips folder: right-click the board strip →
   **Open tips folder**, or use **Open tips folder** in Settings.
2. Copy the contents of `examples/tips/` into it, including `figures/`.
3. The board picks the files up within a few seconds; no restart needed.

The files cover every kind of tip the app understands:

| File | Shows |
| ---- | ----- |
| `2026-10-04-iemdc-abstract.md` | critical deadline, relative reminders, checklist |
| `2026-11-15-ecce-camera-ready.md` | later deadline, `-1w -3d -1d` remind list |
| `group-meeting.md` | weekly recurring event that rolls forward on **Done** |
| `journal-club.md` | monthly recurring event with `color`, `size`, `order`, `created` and a hand-written `paper` block |
| `check-coil-temperature.md` | lab task with location and an image (`figures/coil-thermal.png`) |
| `read-arxiv-2401-12345.md` | reading tip with a quoted arXiv id and a filled `paper` block |
| `read-doi-tie.md` | reading tip with a DOI only, metadata fetched later |
| `rebuttal-notes.md` | plain note with a task list body |
| `backup-nas.md` | a done task with `done_at` |
| `agent-survey-example.md` | agent tip with a question block, an answer and a result block; shows ⭐ |

Dates in the examples are in autumn 2026; edit them so the deadlines are in
your future, otherwise everything shows as overdue.

Format reference: [`docs/TIP-FORMAT.md`](../docs/TIP-FORMAT.md).
